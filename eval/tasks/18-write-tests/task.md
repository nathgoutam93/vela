`dates.vl` has three date functions, correct as they are. Write
`dates_test.vl`: `test` blocks that check them well enough to catch
mistakes. They will be run against the code as it is, where every test
must pass, and against several versions of `dates.vl` with a bug put in,
where your tests should fail. Do not change `dates.vl`.

Run them with `vela test dates_test.vl`.
