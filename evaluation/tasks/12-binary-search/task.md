`search.vl` has two functions on sorted arrays of Int, and
`search_test.vl` tests them. Some tests fail. Find the bugs in `search.vl`
and fix them; do not change the tests, and keep the functions' names and
types.

- `find(xs, x)` returns the index of an element equal to x, or None.
- `count_less(xs, x)` returns how many elements are less than x.

Run the tests with `vela test search_test.vl`.
